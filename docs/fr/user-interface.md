# Interface utilisateur

La disposition de l'éditeur ainsi que les commandes et les touches du travail quotidien. Les nouveaux utilisateurs commencent par le [tutoriel](tutorial.md).

L'éditeur est organisé comme EPLAN : un **ruban** avec l'onglet Fichier (Backstage :
nouveau, ouvrir, enregistrer, import, export, impression, paramètres) et les onglets
*Accueil*, *Insertion*, *Édition*, *Affichage*, *Appareils*, *Liaisons*, *Données de
projet*, *Outils*, *Données de base*, *Plugins* et *Aide*, plus les onglets contextuels
*Espace de montage* (implantation d'armoire) et *Câblage* (assistants) ; une **barre
d'accès rapide** au-dessus (enregistrer, liste d'annulation, changement de page, espace de
travail, recherche de commandes) ; des **panneaux** ancrables pour la page, les
navigateurs, le Centre d'insertion, les propriétés, les messages et chaque outil ; une
**barre d'état** avec position, grille, calque, zoom, langue, résultats du contrôle et les
messages de la session.

| Action | Comment |
| --- | --- |
| Trouver n'importe quelle commande | `Ctrl+Shift+P` / `F3` ou le champ de recherche de la barre d'accès rapide : chaque commande de l'éditeur et des plugins par son nom, son info-bulle ou sa place, et les entrées des menus fixes (*Aligner : Gauche*, *Nouvelle page de garde*, …) ; une commande de menu (*Aligner*, *Panneaux*, *Taille de la grille*, …) ouvre son menu dans une petite fenêtre |
| Touches d'accès | `Alt` (ou `F10`) affiche une lettre sous chaque onglet, une deuxième lettre (au coin d'un bouton) exécute une commande ; `Esc` revient en arrière |
| Placer un symbole | *Insertion › Centre d'insertion* (`Ins`) : recherche (`*` et `?` comme caractères génériques), favoris, utilisés récemment, symboles, macros, appareils issus d'articles, fonctions non placées ; cliquer, puis cliquer dans la page ; `R` pivoter, `M` refléter, `Esc` arrêter |
| Tracer des fils | `W` (*Insertion › Fil*), cliquer le début et les coins, se termine automatiquement sur un point de connexion ; `Space` inverse le coin, `Enter` ou un double-clic termine le fil |
| Outils de dessin | le fil, le texte, les graphiques, les cotations, les définitions de liaison et de câble restent actifs pour l'élément suivant ; `Esc` ou un clic droit termine l'outil. La barre d'état montre l'indication de l'outil avec les touches actuelles |
| Sélectionner / déplacer | clic, `Shift`+clic, glisser dans le vide pour une sélection par fenêtre (de gauche à droite : les éléments à l'intérieur ; de droite à gauche, en pointillé : les éléments qu'elle touche), glisser des éléments pour les déplacer ; pendant le glissement dans l'édition de schéma ou l'implantation d'armoire, le clic droit fait pivoter de 90° dans le sens horaire et `Shift`+clic droit de 90° dans le sens antihoraire. Les touches fléchées déplacent d'un pas de grille ; clic droit pour les commandes de la sélection. Les pages validées, générées et verrouillées peuvent être sélectionnées et copiées, pas modifiées |
| Modifier les propriétés | panneau *Propriétés* avec les onglets *Appareil*, *Affichage*, *Articles*, *Propriétés*, *Liaisons* ; `F2` ou un double-clic met le panneau en évidence, ou montre les propriétés dans une fenêtre près du pointeur quand le panneau est masqué ; plusieurs symboles : leurs champs communs. *Appartient à l'appareil* déplace la fonction vers un autre appareil quand `Enter` est pressé ou que le champ est quitté (`Esc` restaure) ; *Renommer l'appareil* renomme l'appareil entier |
| Structure de page | *Accueil › Propriétés de la page…* (ou clic droit sur une page) : fonction (`=`) et emplacement (`+`) |
| Cadre de structure | *Insertion › Cadre de structure* : cliquer deux coins, puis régler la fonction (`=`) et / ou l'emplacement (`+`) de la zone dans le panneau *Propriétés* (vide = hérité), le coin des identifiants, le décalage du texte et le contour ; saisir le cadre par son contour pour le déplacer |
| Modifications non enregistrées | un projet nouveau ou ouvert (aussi depuis la liste des projets récents, un modèle, la base de données de projets, le coffre ou le serveur de projets) et la fermeture de la fenêtre demandent d'abord : *Enregistrer* enregistre puis continue, *Abandonner les modifications*, *Annuler* ; les modifications non enregistrées restent non enregistrées (`*`) quand l'application est relancée |
| Supprimer une page | *Accueil › Supprimer la page* (ou clic droit sur une page) demande d'abord quand la page n'est pas vide ; les pages validées et les pages verrouillées par un autre utilisateur ne peuvent pas être supprimées ; l'annulation ramène une page |
| Onglets de page | les pages ouvertes récemment sont des onglets au-dessus de la page (les noms longs se terminent par `…`, le nom entier et la description au survol) ; `Ctrl+Tab` / `Ctrl+Shift+Tab` basculent, `Ctrl+W`, la croix de l'onglet courant ou un clic du milieu ferme un onglet |
| Câbles | *Liaisons › Câbles* ; sélectionner des fils › *Affecter au câble* ; fil seul : câble et conducteur |
| Numéros de fils | *Liaisons › Numérotation des fils…* ; fil seul : saisir un numéro (conservé par la numérotation automatique) |
| Macros | sélectionner des éléments, clic droit › *Enregistrer la sélection comme macro…* ; les placer depuis le Centre d'insertion ou *Insertion › Macro…* |
| Configurateur | *Données de projet › Configurateur* : options, règles avec macros de page, *Générer les pages* |
| Modifications en masse | *Données de projet › Modifier dans un tableau* (ou le bouton de tableau d'un navigateur) : appareils, liaisons, bornes, câbles, broches de connecteur, points API, pages, articles et les résultats de la vérification ; filtrer, modifier, remplir, rechercher et remplacer, CSV |
| Contrôle du projet | panneau *Messages* (`F4`) : tableau triable des messages ; un clic montre l'objet, un clic droit accepte, change le niveau ou désactive la vérification |
| Climatisation de l'armoire | implantation d'armoire : sélectionner l'armoire › *Climatisation (CEI 60890)* |
| Borniers / API | *Appareils › Borniers* / *Appareils › Vue d'ensemble API* |
| Connecteurs | placer des broches depuis le groupe de symboles *Connecteurs* ; *Appareils › Connecteurs* pour l'ordre des broches et les deux côtés |
| Révisions | *Données de projet › Révisions* : créer (et valider) des révisions, circuit d'approbation, verrouiller / déverrouiller des pages, voir les modifications |
| Comparer | *Données de projet › Comparer et références* : créer des références, comparer, reprendre des différences |
| Révision | espace de travail ou navigateur *Révision*, *Insertion › Commentaire* et *Insertion › Annotation* (en rouge / en vert) |
| Paramètres | *Fichier › Paramètres* : paramètres du projet (numérotation des fils, renvois, vérifications, marquage, schéma de paramètres) et paramètres utilisateur (apparence, échelle de l'interface, langue, vue 3D dessinée par la carte graphique, opacité des murs de la vue 3D, temps d'image et images par seconde dans la barre de titre, ce qui s'ouvre au démarrage, touches et gestes, ruban, serveurs) dans une seule boîte de dialogue ; *Apparence › Croix de repérage du schéma* prolonge la croix de placement jusqu'aux bords de la zone de dessin |
| Schéma de paramètres | *Données de projet › Exporter les paramètres… / Importer des paramètres…* : la numérotation des fils, les potentiels, les valeurs par défaut et les couleurs des fils, le marquage, les valeurs par défaut des flexibles, les renvois, le schéma de vérification et les calques du projet en un fichier pour d'autres projets (outils `export_settings`, `import_settings`) ; le volet Calques exporte et importe les calques seuls |
| Panneaux | faire glisser l'onglet de n'importe quel panneau (page, navigateurs, Centre d'insertion, propriétés, messages, outils) à côté, au-dessus ou au-dessous d'un autre ou parmi ses onglets ; les outils (rapports, câbles, révisions, articles, …) s'ouvrent en fenêtres flottantes, *Ancrer* dans une fenêtre la place dans l'espace de travail et le menu du panneau (`⋯`) détache de nouveau un panneau ancré ou le ferme (le choix est mémorisé) ; la page ne peut pas être fermée (un clic sur une page la ramène), les navigateurs n'ont pas de croix sur leur onglet ; une barre d'onglets trop étroite pour ses titres montre des icônes et une liste de tous ses onglets (la flèche à côté du menu du panneau) ; *Affichage › Panneaux* affiche ou masque chacun, par zone, et *Réinitialiser la disposition des panneaux* remet les panneaux de l'espace de travail courant à leur place ; les panneaux flottants et les choix d'ancrage appartiennent à leur espace de travail ; `F6` passe d'un panneau à l'autre |
| Espaces de travail | *Affichage › Espaces de travail* ou le sélecteur de la barre d'accès rapide : *Schéma*, *Implantation d'armoire*, *Câblage*, *Montage*, *Révision*, *Préplanification*, chacun avec sa propre disposition des panneaux ; *Enregistrer l'espace de travail…* conserve la disposition et le ruban sous un nom (conservé par l'application) |
| Ruban | les groupes qui ne tiennent pas dans la fenêtre se replient depuis la droite en un bouton avec leurs commandes ; un double-clic sur un onglet ou la flèche à droite le réduit ; *Fichier › Paramètres › Ruban* masque des groupes, ajoute des groupes de commandes personnels et les exporte / importe |
| Touches et gestes | *Fichier › Paramètres › Touches et gestes*, quatre sections. *Raccourcis clavier* : enregistrer, effacer ou réinitialiser les touches de chaque commande (aussi Suppr et les touches fléchées de la page, les touches qui déplacent dans la vue 3D) ; regroupés par onglet du ruban, un filtre cherche dans tous les groupes ; les conflits sont montrés là où les deux touches agissent (la page, l'implantation d'armoire), les touches sont conservées par l'application et montrées dans les info-bulles, les indications et l'aide ; `Esc` et les touches du presse-papiers restent fixes. *Touches de modification* : Shift, Ctrl, Alt ou désactivé pour ajouter à la sélection, ouvrir le lien d'un texte, saisir un seul élément d'un ensemble, inverser *Conserver les connexions* pour un déplacement, pivoter en sens inverse pendant le déplacement, se déplacer plus vite en 3D, défiler latéralement et zoomer par défilement. *Souris* : enregistrer ou ajouter le bouton (avec une touche de modification) qui déplace les vues planes, fait pivoter et déplace la vue 3D, annule un dessin, fait pivoter pendant le déplacement, et les double-clics qui terminent un dessin, ouvrent la sélection et tournent la vue 3D ; le bouton gauche seul reste celui qui sélectionne et dessine. *Molette et tactile* : ce que fait le défilement et sa direction, ce que font deux doigts (déplacer et zoomer ensemble, zoomer seulement, déplacer seulement ; sur les écrans tactiles et les pavés tactiles) et trois doigts sur un écran tactile (comme deux, ou l'un de ces choix). Les conflits sont montrés dans chaque section, chacune a sa réinitialisation |
| Demandes de modification | *Données de projet › Demandes de modification* : demandes, import et export CSV / JSON |
| Export | *Fichier › Export* : PDF, DXF / DWG (page / toutes), SVG, HTML, liste de fils pour la production, implantation d'armoire en 3D (glTF / STEP / IGES / IFC / JT / Parasolid) |
| Importer d'anciens dessins | *Fichier › Import › Importer un DXF / DWG comme page…* |
| Symboles personnels | *Données de base › Éditeur de symboles* ; ils apparaissent sous *Symboles utilisateur* dans le Centre d'insertion |
| Cartouches / formulaires de rapport | *Données de base › Formulaires et cadres* ; par page dans les propriétés de la page |
| Fabrication de l'armoire | onglet *Espace de montage* : *Barre de cuivre*, *Découpe*, *Données CN* (DXF / DWG / CSV) |
| Appareils de porte | *Espace de montage › Porte (face avant)* pour les appareils de porte et les découpes, *Porte (face intérieure)* (en miroir) pour les goulottes et le câblage de la porte ; 3D : *Ouvrir la porte* / *Fermer la porte* |
| Câbler l'armoire | espace de travail *Câblage* : choisir un fil dans la liste ou en 3D, *Câblé* / *Problème* ; *Câblage › Mode tablette* pour les écrans tactiles ; `--wiring` (web : `#wiring`) démarre dans l'espace de travail Câblage avec le mode tablette pour cette session |
| Textes du projet en plusieurs langues | *Données de projet › Langues du projet* : langues cibles, *Collecter les textes du projet*, traduire (ou CSV pour les traducteurs) ; *Données de projet › Exporter en PDF dans la langue* |
| Rapport de vérification | *Outils › Rapport de vérification* (IEC 60364-6 / DIN VDE 0100-600, sans serveur de projets) : les données du rapport, les valeurs à l'origine et l'examen visuel avec des points personnels, les limites, *Signer le rapport*, une section par source TBTS / TBTP et par circuit (remplie à partir du schéma, *manquant* marqué, *Afficher dans le schéma*) ; les valeurs sont reprises quand un champ est quitté ; *Exporter en Excel* ; la page web du serveur de projets montre le même rapport sur une tablette |
| Flexibles / boucles PCT | tracer des fils entre des orifices fluidiques / P&ID ; propriétés et configuration du flexible dans les propriétés du fil ; *Outils › Fluide et procédé* (flexibles, groupes d'appareils, liens électro-fluidiques et *Synchroniser*, boucles PCT) |
| Faisceaux | *Liaisons › Faisceaux* ; sélectionner les fils entre deux appareils › *Affecter au faisceau*, ou par liaison dans les propriétés du fil ; topologie 3D, protections, fixations, traitement des extrémités, KBL, interface faisceau et export 3D dans le panneau |
| Aide | `F1` ouvre le chapitre du tutoriel du panneau utilisé ; le panneau Aide contient le guide rapide (la première heure, avec des liens vers le tutoriel), le tutoriel, les raccourcis clavier ; *Aide › Tutoriel*, *Aide › Page d'accueil* (les 13 chapitres), *Aide › À propos d'OpenECraft*, *Aide › Mentions légales et confidentialité* (la clause de non-responsabilité, la déclaration de confidentialité et, dans un éditeur web hébergé, les mentions légales de son exploitant) |
| Boîtes de dialogue | s'ouvrent centrées sur l'éditeur et gardent la place et la taille qu'on leur a données ; `Esc` ferme celle du dessus, *Annuler* abandonne ce qui a été saisi ; la recherche de commandes se ferme par un clic à l'extérieur |
| Déplacer la vue / zoomer | glisser avec le bouton droit ou du milieu / molette (la molette horizontale et `Shift`+molette déplacent latéralement ; boutons et touches de modification dans *Paramètres › Touches et gestes*), `F` ajuste la page ; *Affichage › Zoom* : ajuster la page, zoom 100 %, zoom avant, zoom arrière |
| Pavé tactile / écran tactile | dans chaque vue 2D et 3D : le pincement zoome, deux doigts déplacent (aussi en même temps que le pincement) ; sur un écran tactile, un doigt agit comme le bouton gauche de la souris. *Paramètres › Touches et gestes › Molette et tactile* : défilement *Automatique* (les pavés tactiles identifiés déplacent, les molettes identifiées zooment) ; *Source de défilement* : *Supposer un pavé tactile Windows* (par défaut) traite un défilement inconnu par points ou par fractions de ligne comme une entrée de pavé tactile, tandis que le défilement par lignes entières et par pages zoome ; *Strict* traite toute source inconnue comme une molette ; *Zoome (molette)* ou *Déplace (pavé tactile)*, la direction du déplacement par défilement inversée, deux doigts réglés sur zoomer seulement ou déplacer seulement, trois doigts sur leur propre choix |
| Se déplacer en 3D | glisser : pivoter ; bouton droit / du milieu ou Shift+glisser : déplacer ; molette : zoom au pointeur (jusque dans une pièce) ; double-clic : regarder ce qui a été cliqué ; `W` `A` `S` `D` / touches fléchées, `Q` `E` : se déplacer (Shift : plus vite) ; barre dans la vue : avant, gauche, droite, arrière, haut, isométrique, *Ajuster* (`Home`) |
| Pages | `Page Up` / `Page Down`, navigateur *Pages* (son menu contextuel ajoute aussi une page de schéma après la page, renumérote et supprime des pages), changement de page de la barre d'accès rapide |
| Annuler / rétablir | `Ctrl+Z` / `Ctrl+Y` ; la liste d'annulation de la barre d'accès rapide annule plusieurs étapes |
| Copier / coller | `Ctrl+C` / `Ctrl+X` / `Ctrl+V`, *Accueil › Couper* / *Copier* / *Coller* |
