Tools

Free tools that run in your browser

Single functions of OpenECraft for a value or a file of your own. They run in your browser with the code of the editor: nothing is uploaded, and nothing needs an account.

Tools

Voltage drop calculator

The voltage drop of a cable from current, length and cross-section, with the smallest cross-section that keeps your limit.

Calculate the voltage drop

DXF and DWG viewer

Look at a DXF or DWG drawing and save it as SVG, PDF or the other of the two formats.

Open the DXF and DWG viewer

EDZ and parts file viewer

See the parts of an EDZ, EPLAN XML, BMEcat or CSV file as a table and save them as CSV or JSON.

Open the parts file viewer
