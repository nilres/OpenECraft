Cost and license

Is OpenECraft free?

Yes. OpenECraft is open source under the MIT and Apache-2.0 licenses: no price, no licenses to count, no account and no expiry, also for commercial work.

Is there a paid version with more functions?

No. There is one OpenECraft, and everything this site describes is in it.

Platforms and data

Which operating systems does OpenECraft run on?

On Windows, Linux and macOS as a desktop program, and in the browser as a web editor with nothing to install. All of them are built from the same code.

Does OpenECraft work offline?

Yes. The desktop program needs no internet connection. The web editor runs in your browser once it is loaded, and your projects stay on your computer.

Where are my projects stored?

In a project file on your computer. Nothing is uploaded. A team can run the project server in its own network to work on shared projects.

Can OpenECraft open EPLAN projects?

Not yet. Projects of EPLAN Electric P8 and AutoCAD Electrical cannot be imported. Parts from EDZ files and EPLAN parts XML are imported with their data, symbols and 3D models, and DXF and DWG drawings as graphics.

Which formats can it export?

PDF, DXF, DWG and SVG for the pages, the panel as glTF, STEP, IGES, IFC and JT, wire lists, marking data, PLC symbol tables and more. The exports of the live demo on this site run in your browser.

Engineering

Which standards do the symbols follow?

IEC 60617 for schematics, with NFPA, GB, GOST and JIS sets, ISO 1219 for fluid power, ISO 10628 for P&ID and IEC 60617-11 for installation plans. Structure identifiers follow IEC 81346.

Can scripts and AI agents work with OpenECraft?

Yes. Every operation on a project is a command of the command line and of the MCP server for AI agents, and plugins in any language add checks, reports, exports and commands.

Is OpenECraft ready for real projects?

It is a young project: the first release was in November 2026. Plan one real project with it beside the tool you use today before you rely on it, and have a qualified person verify the results.

Where do I get help?

From the documentation on this site and from the issue tracker of the project, where problems and wishes are reported.
