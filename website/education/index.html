For schools and training

Learn electrical planning on real software, for free

OpenECraft costs nothing, needs no license server and runs in the browser, so every student works with the same program at school and at home. The project check points out mistakes while they draw.

Try the live demo Open the web editor

Why it suits a classroom

Free for every student

Open source under the MIT and Apache-2.0 licenses: no licenses to count, no accounts, no expiry. Install it on every school computer or use it in the browser.

In the browser

The full editor as a web application. Nothing to install, your projects stay on your computer.

Example projects, simplest first

Each example builds on the one before: from push buttons and lamps through a self-holding relay and a star-delta starter to PLC, panel layout and whole buildings.

A tutorial from the first page

The tutorial walks from the first schematic page to the bill of materials: pages, symbols, wires, parts, terminals, PLC, the project check, reports and the panel layout.

Tutorial

Feedback while drawing

The project check follows every change and leads to the place of each message, so students see their mistakes at once.

In the student's language

20 languages, switched while working: menus, generated reports and check messages follow at once.

Standards from the start

IEC 60617 symbols, structure identifiers after IEC 81346 and reports as in industry, so what is learned carries over to other tools.

For the whole class

The web editor and a project server for shared projects run in the school's own network from Docker images.

Installation guide

Start with an example

The first examples are a lamp circuit, a self-holding relay and a star-delta motor starter; later ones add a PLC, electro-pneumatics, structure identifiers, revisions, control cabinets, rooms and buildings.

See for yourself

The live demo runs the editor's own code in your browser; the web editor is the whole program, nothing to install.
