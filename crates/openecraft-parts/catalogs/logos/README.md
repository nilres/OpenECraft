# Logos of the bundled catalogs

The logo a bundled catalog gets when the parts server installs it (`<id>.svg`,
`openecraft_parts::bundled`). The logos are trademarks of their owners and only
identify the manufacturer of the catalog; administrators replace them on their
server (*Administration › Catalogs › Edit*).

was missing, a `<title>` with the manufacturer, comments and metadata removed):
